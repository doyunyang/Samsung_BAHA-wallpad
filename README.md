# Samsung_BAHA-wallpad
삼성바하 월패드패킷 및 서버데이터
삼성 BAHA-W-2030A 월패드의 RS485 프로토콜 분석 기록입니다. 세대별 장치 ID 차이와 조명 구수(4구/6구)에 따른 패킷 변화를 정리했습니다.

02. 패킷 구조 분석 요약
. Header & ID: 02 10 [04/06] (세대별 상이)
Control Bit: 6번째와 7번째 바이트가 조명 번호와 상태(켜짐/꺼짐)를 결정합니다.
.Bit Mask: 일괄 제어 시 3F를 사용하는 것으로 보아 각 비트가 조명 1~6번에 매핑됨을 알 수 있습니다.
Checksum: 8번째 바이트가 체크섬이며, 데이터 값의 변화에 따라 가변적입니다.
- **4구형 (`0F`):** $2^0+2^1+2^2+2^3 = 1+2+4+8 = 15$ (`0F`)
- **6구형 (`3F`):** $2^0+2^1+2^2+2^3+2^4+2^5 = 1+2+4+8+16+32 = 63$ (`3F`)

이 원리를 통해 특정 조명들만 조합하여(예: 1, 3, 5번만 제어) 패킷을 생성하는 것이 가능합니다.
