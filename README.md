## 3. 구조 분석 요약
- **Header & ID:** `02 10 [04/06]` (세대별로 상이함)
- **Control Bit:** 6번째와 7번째 바이트가 조명 번호와 상태(켜짐/꺼짐)를 결정합니다.
- **Bit Mask:** 일괄 제어 시 비트 연산을 통해 여러 조명을 동시에 제어합니다.
    - **4구형 (`0F`):** $2^0+2^1+2^2+2^3 = 15$ (`0F`)
    - **6구형 (`3F`):** $2^0+2^1+2^2+2^3+2^4+2^5 = 63$ (`3F`)
- **Checksum:** 8번째 바이트가 체크섬이며 데이터 값에 따라 가변적입니다.

> **Tip:** 이 비트 연산 원리를 활용하면 1, 3, 5번만 켜는 등 사용자 정의 패킷 생성이 가능합니다.
